# Chathuni Nimesha — Portfolio

Personal portfolio for **J.I Chathuni Nimesha Gammanpila**, an Information Technology undergraduate and full-stack developer.

Live site: [https://chathuni-nimesha.github.io/](https://chathuni-nimesha.github.io/)

## Purpose

This site presents selected academic and personal software work: full-stack web applications, an AI support workspace MVP, Android development, UI/UX, and research.

## Technology

The portfolio itself is a static site:

- HTML
- CSS
- JavaScript

It is designed to stay lightweight for GitHub Pages. Project work shown on the site uses stacks such as React, Next.js, Node.js, Java, Spring Boot, Python, FastAPI, and Kotlin.

## Sections

- Home
- About
- Skills
- Projects
- Experience
- Education
- Research
- Contact

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
# Python
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment

This repository is published with **GitHub Pages** from the `main` branch.
